1. Experimental set-up

Planned, not active. The research design describes this phase only well enough to keep Phase 1 decisions compatible with it; it is respecified once Phase 1 lands.

  1. 1

    From pixels to zones

    Pixel-level attribution cannot be passed to an LLM directly; aggregating it to zone summaries is a Phase 3 design problem that Phase 1 must not foreclose.

  3. 2

    Context document

    A structured JSON document per target zone with three blocks: predictions, explanations, and external context (ERA5 weather variables; country, elevation and SoilGrids soil class; image-texture descriptors where available).

  5. 3

    Report generation

    An LLM that follows the required output format reliably and is reproducible, generating at temperature zero and constrained to the context document.

  7. 4
    RQ3

    Traceability

    Each report scored for traceability against its source. If explanations fail their faithfulness checks, the context document can still operate from predictions and calibrated uncertainty alone.
